# Systematic review materials

These files document the search and selection of the systematic review. Records were managed in Parsifal and selected by a single reviewer.

| File | Content |
| --- | --- |
| [search_strategies.md](search_strategies.md) | Exact query, field and platform-specific adaptation for each of the six sources |
| [full_text_assessment.csv](full_text_assessment.csv) | The 74 reports sought for full-text assessment, with the final decision and the primary exclusion reason |

## Selection flow

| Stage | Records |
| --- | ---: |
| Records identified from the six databases | 783 |
| Duplicates removed | 97 |
| Records screened by title and abstract | 686 |
| Records excluded at title and abstract | 612 |
| Reports sought for full-text assessment | 74 |
| Reports not retrieved | 1 |
| Reports assessed for eligibility | 73 |
| Reports excluded after full-text assessment | 54 |
| **Studies included** | **19** |

## Full-text exclusions

When several criteria applied, one primary reason was recorded.

| Primary reason | Reports |
| --- | ---: |
| Exclusively indoor environments | 35 |
| No outdoor, off-road, agricultural, road, urban or campus, cave or tunnel, or mixed evaluation | 7 |
| Not focused on autonomous navigation or motion planning | 4 |
| Platform other than a wheeled or tracked ground robot | 4 |
| No empirical evaluation of the navigation approach | 3 |
| Language other than English | 1 |
| **Total** | **54** |
